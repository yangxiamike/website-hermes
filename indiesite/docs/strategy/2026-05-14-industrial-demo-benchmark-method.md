# 工业独立站 Demo Benchmark 方法

日期：2026-05-14
阶段：产品制作阶段
Owner：Hermes
适用资产：公司官网、行业样板站、旧站改造案例、服务页、诊断报告模板

## 1. 当前修正

前几版 demo 的问题，不只是页面细节问题，而是制作方法问题。

不能凭空“想一个工业网站”，也不能只用通用 AI/模板审美去拼页面。正确方法应该是：

1. 先看优秀欧美工业企业网站。
2. 再看同行竞品企业网站，尤其是阀门、流体控制、机械零部件、工业设备等真实 B2B 网站。
3. 再看 21st.dev、Tailwind UI、Framer、Webflow 等现代模板/组件网站，吸收 UI/UX 和组件表达。
4. 最后把这些参考转译成适合中国出口工厂的英文独立站 demo。

这就是人类社会做事的基本逻辑：站在巨人肩膀上，而不是从空白开始。

## 2. Demo 制作的新原则

一句话：

用欧美工业网站的信息组织建立专业感，用现代模板组件提升观感，用中国工厂真实能力证明建立信任。

不再接受：

- 只靠 AI 想象出来的页面
- SaaS/AI 工具站风格套到工业企业
- 抽象大词、渐变光效、玻璃卡片堆叠
- 只有“High quality / Competitive price / Best service”的空泛文案
- 首页只是产品图堆砌
- 产品详情页没有参数、标准、材质、测试、资料下载、RFQ

## 4. 推荐 Demo 风格方向

### 方向 1：Modern Industrial

适合：阀门、机械、自动化、工业零部件。

关键词：

- 稳重
- 工程感
- 真实制造
- 技术可信
- 全球供应

视觉建议：

- 深蓝 / 石墨黑 / 冷灰 / 白色
- 少量橙色或工业黄作为 CTA 强调
- 真实工厂、产品、检测设备、应用现场图片
- 参数表、技术标签、流程图、资料下载模块

### 方向 2：Technical Editorial

适合：材料、检测、认证、工程服务、研发型制造。

关键词：

- 技术白皮书感
- 行业报告感
- 克制、专业、可信

### 方向 3：Product System Showcase

适合：SKU 多、产品族多的出口工厂。

关键词：

- 产品体系清晰
- 分类/筛选友好
- 参数驱动
- 下载资料完整

## 5. 阀门样板站的新首页结构

推荐顺序：

1. Header
   - Home
   - Products
   - Industries
   - Solutions
   - Quality
   - Resources
   - About
   - Contact
   - Request a Quote

2. Hero
   - 标题：Industrial Valve Solutions for Critical Flow Control
   - 副标题：覆盖产品类型、行业、标准、定制和出口能力
   - CTA：View Products / Request a Quote / Download Catalog
   - 视觉：阀门产品 + 工况/管线/工厂检测场景

3. Trust Strip
   - ISO / API / CE / PED 等认证位置
   - Export markets
   - Years of manufacturing
   - Testing before shipment
   - Engineering response

4. Product Categories
   - Ball Valves
   - Gate Valves
   - Globe Valves
   - Check Valves
   - Butterfly Valves
   - Control Valves
   - Actuated Valves
   - Strainers

5. Industry Applications
   - Oil & Gas
   - Chemical Processing
   - Water & Wastewater
   - Power Generation
   - Marine & Offshore
   - HVAC
   - Mining

6. Manufacturing / Engineering Capability
   - Materials
   - Standards
   - Customization
   - Actuation options
   - OEM/ODM support

7. Quality & Testing
   - IQC / machining / assembly / pressure testing / final inspection / packing inspection
   - Shell test
   - Seat leakage test
   - Hydrostatic test
   - PMI / NDT / MTC / test report

8. Featured Products
   - 具体产品系列，不只是分类
   - 每张卡含 size、pressure、material、standard、connection

9. Project / Application Cases
   - 行业
   - 工况
   - 阀门类型
   - 材质
   - 压力等级
   - 结果

10. Resources
   - Catalog
   - Datasheet
   - IOM Manual
   - Certificate
   - Valve Selection Guide

11. Final RFQ CTA
   - 提醒客户提供 medium、pressure、temperature、size、material、standard、quantity、application

- Body material

如果没有这些，页面看起来就不像真实阀门企业。

## 7. 新的制作流程

以后做正式 demo，流程改为：

1. Benchmark
   - 先收集 8-12 个优秀欧美工业网站
   - 收集 5-8 个同行竞品网站
   - 收集 5-10 个现代模板/组件参考

2. Pattern Extraction
   - 提炼首页结构
   - 提炼产品页结构
   - 提炼行业页结构
   - 提炼质量/认证/下载/RFQ 模块
   - 提炼视觉风格和组件风格

3. Demo Brief
   - 明确 demo 行业
   - 明确目标买家
   - 明确产品族
   - 明确页面矩阵
   - 明确信任证据链

4. Visual Direction
   - 设定色彩、字体、图片策略、组件风格
   - 明确要避免的 SaaS/AI 模板感

5. Prototype
   - 先做静态高质量版本
   - 不追求复杂功能，优先真实感和信息架构

6. Engineering Version
   - 响应式
   - SEO metadata
   - 表单路径
   - 下载入口
   - 内链结构

7. Nora QA
   - 是否像真实工业企业
   - 是否采购商能看懂
   - 是否有 AI 味
   - 是否存在虚假承诺
   - 是否有 P0/P1/P2

## 8. 下一轮 demo 的判断标准

下一版优秀模板 demo 必须满足：

- 看起来像真实欧美/国际工业企业网站，而不是 AI 生成模板
- 首页有清晰采购路径
- 产品详情页有行业真实参数
- 行业应用页能反向证明专业理解
- 质量页面有测试、认证、文件、追溯逻辑
- 资料下载中心符合工业采购习惯
- RFQ 表单是技术询盘，不是普通留言
- 视觉现代，但不过度 SaaS 化
- 内容克制、具体、可验证

## 9. 当前结论

创始人的纠正是对的。

前几版 demo 的不足，不应该只靠局部修文案或调 UI 解决，而要升级制作方法：

从“AI 生成页面”改成“benchmark → 提炼模式 → 工业化转译 → demo 生产 → QA Gate”。

这条流程以后应作为独立站样板资产制作的默认方法。
