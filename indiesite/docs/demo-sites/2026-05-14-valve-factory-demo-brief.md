## 1. 为什么选门阀工厂

### 1.1 买家决策更重视信任，不只是价格

门阀类产品通常涉及：

- 工况适配
- 材质选择
- 压力等级
- 标准认证
- 质量测试
- 交付稳定性
- 项目经验
- 售前技术沟通

海外买家不会只看图片和低价。网站必须证明：这家工厂懂行业、能定制、能质控、能交付。

### 1.2 很适合展示“旧站改造”的价值

大量传统阀门工厂英文站容易出现这些问题：

- 首页像产品目录，没有买家决策路径
- 英文标题空泛，例如 “Professional Valve Manufacturer”
- 产品页只有型号和参数，没有应用场景
- 工厂能力、检测流程、证书和出口经验没有结构化呈现
- 询盘 CTA 弱，买家不知道该提供哪些工况信息

这些问题正好对应我们的服务能力。

### 1.3 内容资产可沉淀

门阀行业可以延展出多种展示资产：

- 行业样板首页
- 产品分类页：Ball Valve / Gate Valve / Check Valve 等
- 产品详情页样板
- Factory Capability 页面
- Quality Control 页面
- Application 页面：Oil & Gas / Water Treatment / Chemical / HVAC
- 网站诊断报告样例
- 改造前后对比案例
- 英文内容承接样例

## 2. 样板站定位

### 2.1 Demo 工厂设定

暂定虚拟品牌：

**Northvale Flow Control**

品牌说明：纯虚拟样板品牌，用于展示，不代表真实客户。

工厂设定：

- 中国阀门制造商
- 面向海外工业采购商、工程商、OEM 客户
- 主营工业阀门和定制流体控制解决方案
- 具备铸造 / 机加工 / 装配 / 压力测试 / 质检能力
- 可按 ANSI / API / DIN / JIS 等标准生产
- 支持 OEM、项目订单和批量采购

注意：所有证书、客户、项目、产能数字在未验证前必须用 demo 表达，不得伪造成真实客户案例。

## 3. 首页核心表达方向

### 3.1 英文定位句

备选方向：

1. Industrial Valve Manufacturing for Demanding Flow Control Applications
2. Custom Industrial Valves Built for Pressure, Corrosion, and Project Reliability
3. Reliable Valve Manufacturing Partner for Global Industrial Projects

推荐先用：

**Industrial Valve Manufacturing for Demanding Flow Control Applications**

原因：专业、克制、不夸张，能承接多应用场景。

### 3.2 首页应该回答的买家问题

海外买家进入网站后，首页要快速回答：

1. 你们做什么阀门？
2. 适合哪些行业和工况？
3. 能不能按标准和图纸定制？
4. 质量怎么保证？
5. 有哪些制造和测试能力？
6. 我应该如何发询盘？需要提供哪些参数？

## 4. 建议网站结构

### 4.1 MVP 页面

第一版先做 5 个页面，不扩张：

1. Home
2. Products
3. Product Detail Template：Industrial Ball Valve
4. Factory Capability
5. Quality Control / Contact 可合并为区块或独立页

### 4.2 首页模块顺序

1. Hero：行业定位 + 核心 CTA
2. Product Categories：Ball / Gate / Globe / Check / Butterfly Valves
3. Application Industries：Oil & Gas / Chemical / Water Treatment / Power / HVAC
4. Engineering & Customization：材质、压力等级、连接方式、标准
5. Factory Capability：加工、装配、测试、包装
6. Quality Control：pressure test、material inspection、dimensional inspection
7. Inquiry Guide：引导买家提交介质、压力、温度、材质、数量、标准
8. CTA：Request a Quote / Send Your Valve Specification

## 5. 服务展示重点

这个 demo 不只是“好看的网站”，要证明我们会做三件事：

### 5.1 把产品目录变成买家决策路径

从“展示很多阀门图片”改为：

- 产品类型
- 应用场景
- 技术参数
- 定制能力
- 质量验证
- 询盘信息

### 5.2 把工厂能力讲成信任资产

不是简单写 “we have advanced equipment”，而是展示：

- 工序能力
- 检测节点
- 可执行标准
- 订单协作流程
- 出口包装和交付经验

### 5.3 把英文内容从泛泛介绍改成采购语言

避免：

- high quality
- best price
- professional manufacturer
- advanced technology
- customer first

改为更具体的采购语言：

- pressure rating
- body material
- sealing material
- working medium
- end connection
- inspection report
- drawing-based customization
- project documentation

## 6. Nora 风险边界

必须避免：

- 虚构真实客户名、真实项目、真实证书编号
- 写 guaranteed quality / guaranteed delivery / best price
- 写过度 SEO 化、堆关键词的英文
- 把 demo 包装成真实案例
- 用未经授权的真实工厂图片、logo、证书

允许：

- 使用虚拟品牌
- 使用 demo/simulated project wording
- 使用通用制造流程描述
- 使用公开可商用或自制示意图
- 在页面底部标注 Sample demonstration site when necessary
