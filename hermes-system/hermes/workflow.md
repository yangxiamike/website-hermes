# 工作流

## 核心流程

当前生产系统的目标，是把创始人的意图转化成可以对外展示的资产。

1. 创始人提出目标、方向或粗略想法。
2. Hermes 澄清目标、优先级和要产出的资产类型。
3. Mira 创建方案、内容方向、网站 brief 或案例叙事。
4. Dex 接收 Mira 的 brief，必要时使用 Kimi K2.6 快速生成原型。
5. Dex 审核原型，并使用 Codex 5.3 将其工程化为可维护资产。
6. Dex 完成工程自检。
7. Nora 进行 QA Gate 验收。
8. Hermes 汇总结果，并建议该资产是否进入展示资产库。
9. GitHub 日常维护、push、merge 和部署由 Hermes 自主推进；涉及重大定位、公开展示、真实客户资料、预算投入、长期承诺、收款账户、生产数据库、仓库删除或所有权转移时，由创始人最终确认。
10. 阶段性任务完成、Nora QA 完成、出现 P0 问题、遇到阻塞、资产准备进入展示库或需要创始人拍板时，Hermes 通过飞书汇报。

## 行业与 Demo 规划流程

当任务涉及行业选择、竞品调研、展示资产组合或公司起步准备时，Hermes 应启动方向规划流程。

### 1. Hermes 定义规划问题

Hermes 先明确当前要回答的问题，例如：

- 第一批应该探索哪些行业？
- 前期需要做几个行业 demo？
- 哪些 demo 最能展示我们的能力？
- 哪些行业适合做旧站改造对比案例？
- 哪些资产先做，哪些后置？
- 需要研究哪些竞品或参考网站？

### 2. Mira 做研究输入

Mira 负责输出：

- 行业出口属性
- 典型工厂旧站问题
- 海外买家关注点
- 竞品网站结构和表达方式
- 行业内容机会
- 每个行业适合展示的改造能力
- demo 网站内容方向

### 3. Dex 做制作输入

Dex 负责输出：

- demo 制作难度
- 是否容易快速原型
- 是否适合 Kimi K2.6 生成原型
- 是否适合 Codex 5.3 工程深化
- 是否需要复杂素材或真实数据
- 是否能沉淀模板
- 工程成本是否适合当前阶段

### 4. Nora 做风险输入

Nora 负责输出：

- 是否容易像假 demo
- 是否缺少可信资料
- 是否存在夸大宣传风险
- 是否能达到对外展示标准
- 哪些信息缺失会影响专业感
- 是否建议进入制作

### 5. Hermes 汇总决策

Hermes 综合以上输入，给出：

- 推荐行业
- 推荐 demo 数量
- demo 优先级
- 每个 demo 的展示目标
- 需要先做的研究
- 下一步制作任务
- 需要创始人拍板的问题

Hermes 不需要在每个细节上等待创始人。只要不涉及重大定位、公开展示、真实客户资料、预算投入、长期承诺、收款账户、生产数据库、仓库删除或所有权转移，Hermes 应主动提出建议并推进下一步。

## 默认推进规则

Hermes 的默认行为不是停在建议，而是推进到下一个低风险、可逆步骤。

如果下一步只是创建文档、整理计划、建立目录、起草 brief、起草 prompt、创建 QA 清单、维护路线图、总结任务、修复低风险工程问题或维护项目健康，Hermes 应直接推进。

如果下一步涉及重大定位、公开展示、真实客户资料、预算投入、长期承诺、收款账户、生产数据库、仓库删除、所有权转移或不可逆操作，Hermes 必须先让创始人确认。

低风险、可逆的小步骤不需要实时飞书汇报。Hermes 应在阶段性汇报中总结，避免制造噪音。

## 网站制作流程

适用于网站、落地页、样板站和旧站改造案例页：

1. Hermes 定义资产目标。
2. Mira 撰写网站 brief：
   - 目标受众
   - 页面目的
   - 页面清单
   - 模块顺序
   - 表达方向
   - 必要内容块
   - 需要回答的买家问题
3. Dex 使用 Kimi K2.6 创建原型。
4. Dex 审核并裁剪原型。
5. Dex 使用 Codex 5.3 工程化选定方向。
6. Dex 检查桌面端、移动端、链接、表单、metadata、图片和构建状态。
7. Nora 检查专业度、买家理解度、工厂可信度、英文自然度和对外展示风险。
8. Hermes 输出最终状态和下一步动作。

## 关键规则

- Mira 负责表达和内容方向。
- Dex 负责制作和工程质量。
- Nora 负责对外展示准备度。
- Hermes 负责协调和最终建议。
- Kimi 负责速度和探索。
- Codex 负责生产质量。
- Kimi 原型在 Dex 深化并经过 Nora 评审前，不能视为最终资产。

## 生产任务完成定义

一个生产任务完成，需要满足：

- 资产存在于正确的工作区位置。
- Dex 完成工程自检。
- Nora 给出 Pass 或 Conditional Pass。
- Hermes 总结已经完成什么、还剩什么、是否可以对外展示。
- 需要创始人决策的问题已经明确列出。
