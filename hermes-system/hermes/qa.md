# QA Gate

## 目的

QA 的目的，是防止未完成、泛泛、风险高或 AI 味明显的作品进入公司的对外展示资产库。

Nora 负责 QA Gate。Hermes 根据 Nora 的评审结果判断资产是否进入下一阶段。

## 验收结果

### Pass

资产可以进入展示资产库，或在不需要额外创始人批准的情况下对外展示。

### Conditional Pass

资产可以进入下一阶段，但必须修复列出的 P0 问题，或由创始人明确接受风险。

### Fail

资产不能对外展示。必须经过明显修改后再重新评审。

## 问题等级

### P0

对外展示前必须修复。

示例：

- 页面坏掉或布局不可用
- 移动端严重失败
- 询盘路径断裂
- 英文尴尬或 AI 味明显
- 有虚假或高风险宣传承诺
- 缺少核心产品或服务信息
- 看起来像未完成 demo

### P1

建议本轮修复，因为会影响专业度、可信度或转化。

示例：

- 模块层级弱
- 信任元素泛泛
- 没有回答买家关键问题
- 案例说明太薄
- CTA 弱
- 视觉风格不统一
- 改造前后价值不清楚

### P2

可以后续优化。

示例：

- 更多内容样例
- 附加动效
- 进一步 SEO 优化
- 更多案例细节
- 次要视觉打磨

## QA 检查清单

Nora 应检查：

- 这个资产是否符合中国出口工厂场景？
- 工厂老板能否理解它为什么对业务有帮助？
- 海外买家能否理解产品、能力和询盘路径？
- 英文是否自然、具体、不泛泛？
- 页面是否避免了 AI demo 和模板站感觉？
- 在需要的地方是否有产品细节、应用、定制能力、认证、产能或证明点？
- 询盘路径是否清楚？
- 移动端体验是否可接受？
- 信任元素是否可信？
- 这个资产是否证明了我们未来想售卖的某种能力？
- 是否存在公开承诺、隐私或客户资料风险？

## QA 输出格式

Nora 应输出：

```text

P0 问题：
- ...

P1 问题：
- ...

P2 问题：
- ...

最终建议：
...
```
