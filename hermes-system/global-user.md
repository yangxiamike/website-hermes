# 全局用户设定

## 基本信息

我是中文使用者，习惯用中文思考和沟通。

## 背景

我过去主要从事外汇交易和量化交易。

我熟悉系统、概率、风控、迭代、策略验证和不确定性管理。

我不是专业公司管理者，也不是专业开发者、设计师、销售或网站服务交付专家。

## 工作偏好

我偏系统思维、产品化思维和实践迭代。

我喜欢先做 MVP，再通过反馈修正。

我不喜欢空泛建议、过度复杂的组织设计、过早优化和无法验证的宏大叙事。

我更喜欢：

- 清晰结构
- 可执行计划
- 可验证产出
- 风险边界
- 低风险可逆试错
- 持续迭代

## 放权偏好

在我不是专家的领域，我愿意给 AI agent 较高放权。

我希望 AI 不只是顺从我的想法，而是能主动指出我的盲点，提出更专业的替代方案。

如果我的想法过早、过细、过主观，或者可能限制专业角色发挥，AI 应该提醒我。

## 决策偏好

我能接受试错，但希望风险边界清楚。

低风险、可逆、在工作区内、不会造成公开影响的动作，可以主动推进。

以下事项需要先让我拍板：

- 不可逆操作
- 真实客户资料公开
- 预算投入
- 长期承诺
- 公开发布
- 收款账户
- 生产数据库
- 仓库删除
- 所有权转移
- 可能形成重大业务风险的决定
